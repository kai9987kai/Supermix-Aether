# Evidence status

The implemented hypothesis is narrow: can learned phase/spatial communication improve delayed-cue action performance relative to simpler communication in a fixed sparse recurrent model?

The primary metric is mean executed query success per independent training seed. Controls are scalar, scalar-matched, vector, attention, phase and modes; wave is the candidate. Training seeds share topology, base initialization and support examples across protocols. Support/query numeric seed blocks are disjoint. The task has only six fixed goal configurations, so seed isolation is not task-family or geometry transfer.

The optimizer is AdamW with supervised expert-action cross entropy, ordinary backpropagation through time and gradient clipping. Expert observations/actions are generated by actually stepping a separate world. A hidden goal is available to the teacher only. Learned action evaluation receives the partial observation API and has no teacher access.

The pilot is exploratory. Confidence intervals bootstrap paired training-seed effects, not timesteps or episodes within one trained model. Three seeds cannot establish an advantage. Promotion requires a positive lower paired bound versus every declared control, longer-delay performance within the retention margin, replay/integrity checks and verified resource comparability. The last gate is unestablished in this milestone, so no model is promoted by the supplied runner.

Longer-delay evaluation measures retention of an initial cue under a shifted delay. It does not measure resistance to catastrophic forgetting after sequential task learning. Phase interventions use their own recorded deterministic seeds. Packet loss/noise/latency reference tests establish software behavior, not trained robustness.

The observatory reports actual outputs and preserves unsuccessful candidates. Falling support loss is useful implementation evidence but does not establish useful communication. A negative or inconclusive result is retained. No result here establishes self-assembly, recursive self-improvement, biological fidelity, general intelligence or real-world reliability.

The larger thirty-seed configuration is supplied for future exploration; it has not been executed as part of the first milestone. A confirmatory protocol should freeze task selection, compute-matched controls, power/precision choice and multiple-comparison treatment before collecting fresh data. The proposal's referenced papers and repository capabilities have not been independently audited in this build.

## Executed 7 November 2026 pilot

| Protocol | Mean query success | Mean longer-delay success |
| --- | --- | --- |
| Scalar | 16.7% | 20.8% |
| Scalar-matched | 20.8% | 20.8% |
| Vector | 20.8% | 20.8% |
| Attention | 20.8% | 20.8% |
| Phase | 20.8% | 20.8% |
| Modes | 16.7% | 20.8% |
| Wave | 16.7% | 20.8% |

These are means over three paired training seeds, with 24 query episodes per seed and condition. Wave equaled scalar on every seed; it was 0.0417 below four simpler communication controls on the mean success metric. Its seed-level bootstrap interval versus scalar is [0,0] because all three observed paired differences are zero; that degenerate small-sample interval is not evidence of equivalence in the population. Zero gain, packet erasure, shuffled phases and randomized phases all left wave success unchanged in this pilot. Training loss decreased for all 21 models; decreasing loss did not establish useful wave communication.

The raw run preserves its original source snapshot. Subsequent changes harden rejected-checkpoint loading and update documentation; they do not change the successful forward/training path. Final-code replay is audited separately in `reports/training-audit.json`.
