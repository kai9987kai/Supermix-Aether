# AETHER roadmap and implemented boundary

| Stage | Status here | Acceptance before a capability claim |
| --- | --- | --- |
| P0: preserve Sonapse | Deferred; no Sonapse source edited or imported | Pin exact source/checkpoints; disabled identity, frozen query and replay against the owning runtime |
| P1: NeuroWave-X | Implemented CPU prototype; exploratory experiment | Stronger task families, resource-matched controls and independent replicated behavioural advantage |
| P2: EvoTissue / SynapseForge | Proposed | Real topology/learning-state changes, synchronized execution buffers, held-out repair/adaptation, retention and resource gates |
| P3: GraftBridge / integrations | Proposed | Source/licence audit; typed interfaces, intervention-preserving transfer, negative donor controls and correlated-failure tests |
| P4: HyperWorld / MemoryEcology | Proposed | Actual 4D movement/collisions/sensors and geometry-specific controls; factorial memory-carrier interventions |
| P5: compiler / research fabric | Proposed beyond current report tooling | Typed validated graph IR, independent backend parity, streaming experiments and replicated publication artifacts |

Prioritize communication-demanding tasks with novel routes and distractions, then train/evaluate under explicitly matched reference disturbances. Profile active computation, optimizer state, runtime memory and inference latency rather than treating tensor shapes as compute equality. Freeze a future experiment before adding topology growth or learned local rules.

Do not add placeholder modules for unbuilt stages. Each stage should land as functional, independently testable software with its own negative controls and evidence record. New adapters are optional additions; preservation of existing projects must be established at their exact source revisions rather than assumed from names or older audits.
