# AETHER Live Lab Implementation Plan

> **For agentic workers:** Use subagent-driven development or native execution; tasks have disjoint file ownership.

**Goal:** Replace the static-only entry point with a live, measured neural execution and adaptation workbench.

**Architecture:** A pure session engine feeds an SSE/HTTP coordinator; a browser UI consumes immutable frames. A separate cloned-model trainer produces audited candidates.

**Tech Stack:** Existing Python 3.12/PyTorch/NumPy, standard-library HTTP, vanilla HTML/CSS/JS.

**Spec:** ../specs/2026-11-07-live-lab-design.md

## Global Constraints

- Preserve all files under reports/pilot-2026-11-07 and its verified receipt.
- Default runtime remains 512 neurons, 16 regions, 96 region links, 4 modes, FP16 messages.
- The live UI uses actual model/world state. Demo observations are exploratory, not benchmark or general-intelligence evidence.
- Live query cannot change parameters. Training clones active weights and applies only after an explicit UI action and retention check.
- Single shared local session; mutation serialization and bounded compute/history/clients.

## Review Focus

- Pause/reconnect cannot advance extra ticks or cause multiple schedulers.
- Invalid configuration must not partly reset the episode or consume RNG state.
- Paired branches start identically and report movement-locked actions distinctly.
- Session training cannot mutate source checkpoints or the active model before application.
- Path traversal, foreign-origin control, unbounded requests/history and interrupted jobs fail coherently.

### Task 1: Live execution engine

**Owner files:** aether/live/session.py, aether/live/channel.py, aether/live/__init__.py, tests/test_live_session.py, tests/test_live_channel.py; narrowly extend aether/kernel/runtime.py with optional packet_transform in step/_messages preserving the old default.

**API:** LiveSession(model, *, seed=2077, delay=3, horizon=9, provenance=None); `.step() -> dict`, `.snapshot() -> dict`, `.configure(**settings) -> dict`, `.reset(seed=None)`, `.replace_model(model, provenance=None)`, `.export() -> dict`. Valid settings: intervention ('none','zero_gain','erase_packets','shuffle_phase','random_phase'), loss_probability [0,1], noise_std [0,1], latency_ticks integer[0,4], bandwidth_fraction[0,1], delay integer[1,12]; horizon=delay+6. Changing settings resets paired worlds on current seed. Engine does not own scheduler/thread/HTTP.

**Frame contract:** schema:'aether.live.frame.v1', sequence:int, episode:int, seed:int, tick:int, done:bool, settings:dict, provenance:dict, model:{protocol,neurons,regions,modes,digest,residual_gain,parameter_count}, topology:{links:[[src,dst],...]}, candidate/control:{position:[x,y,z],trajectory:[[x,y,z]],goal:[x,y,z],success:bool,done:bool,return:number,action:int|null,probabilities:[7],regions:[{id,activity}],mode_energy:[K],links:[{source,target,energy}],payload_bytes:int}, comparison:{effective_action_differences,waiting_action_differences,position_distance,return_delta}, history:[{tick,action,control_action,movement_enabled,reward,control_reward}]. Snapshot uses cached measured telemetry, no additional inference.

- [x] Test zero-impairment identity, deterministic disturbances, pause-free pure step semantics, resets, validation atomicity, query digest, telemetry and export bounds.
- [x] Implement actual transformed packets and paired world stepping; test scalar and zero-link cases.
- [x] Run focused engine tests and existing runtime tests.

### Task 2: Browser workbench

**Owner files:** aether/live/web/{index.html,app.js,styles.css} only.

**API consumed:** GET /api/state -> frame extended with playing,speed,checkpoints:[{id,label,protocol,seed}], selected_checkpoint,training:{status,progress,total,curve,candidate,comparison,error},stats:{episodes,successes}; GET /api/events SSE event:'frame'; POST /api/control JSON {action:'play'|'pause'|'step'|'reset'|'configure'|'checkpoint'|'speed'|'train'|'apply'|'rollback',...}. configure uses settings object, checkpoint uses id, speed uses value (1..8), reset optional seed, train updates(1..100). POST responds updated frame, errors JSON {error}. GET /api/export downloads JSON. GET /study/ old report.

### Task 3: Candidate adaptation

**Owner files:** aether/live/training.py, tests/test_live_training.py (root).

**API:** TrainingJob handles asynchronous cloned candidate, progress and cancellation; `.start(model,updates,output_root)`, `.snapshot()`, `.candidate_model`, `.can_apply`, `.cancel()`. It must not run more than one worker at once. Fixed support seeds >=3e9, query >=4e9, retention >=5e9. CPU threads1; max100 updates, batch8; observed current task delay. Before/after eval on same12 query/retention worlds; record limitations and receipts.

- [x] Test active-weight immutability, executed optimization, valid before/after pairing, retention gate, cancellation and no overwrite.
- [x] Implement bounded training, actual progress, saved candidates/evidence and local eligibility.
- [x] Run focused tests and an actual512-neuron training job.

### Task 4: HTTP/SSE scheduler

**Owner files:** aether/live/server.py, tests/test_live_server.py (dedicated worker); root owns CLI integration.

**API:** `LiveApplication(study_dir, output_root=None)` loads checkpoint catalog with wave-11 default; methods `.state()`, `.control(payload)`, `.export()`, `.close()`; `create_server(application, host='127.0.0.1',port=8789)` returns server, and `serve_live(...)` blocks with clean shutdown. Scheduler thread runs once per app, stopped via close; step/control locked, speed1..8, auto-restart completed paired episodes on next scheduler tick; start paused, root launches and presses Play for delivery. TrainingAPI above integrated when available; missing temporary import is not a shipped fallback.

- [x] Implement bounded streams and request handling, app coordinator and clean shutdown.
