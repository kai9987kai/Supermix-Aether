# Training audit: recorded exploratory pilot

The pilot provides no demonstrated wave advantage. Wave, scalar and modes average 16.67% query success; scalar-matched, vector, attention and phase average 20.83%. Three independent training seeds cannot satisfy the predeclared 30-seed confirmation requirement, and resource comparability is not established.

All 21 saved checkpoints passed exact replay with the final current runtime, including recorded query, longer-delay retention and wave interventions. Each same-seed initial model digest matched the recorded initial digest. Scalar edge, input and output weights changed in every checkpoint. In all 18 auxiliary checkpoints, the residual gain moved from exact zero and message encoder/decoder weights changed. Protocol-specific attention, phase and mode parameters changed in their active arms; unused routing parameters stayed unchanged. These are evidence of optimization activity, not evidence of an advantage.

Each arm used the same 40 updates, 320 teacher episodes and 1,600 executed support steps per training seed. Query and retention each contain 24 paired episodes per seed. Across the three training seeds, all 960 support seed IDs, 72 query seed IDs and 72 retention seed IDs are disjoint across splits. The environment nevertheless contains only six fixed goal tasks: the two signs of each axis at distance two from the origin. Query seeds resample these tasks; no held-out geometry is tested.

Across the 12 seed/intervention pairs (three seeds times four interventions), 75 of 288 paired action sequences changed relative to the intact wave policy, all in seed 47: zero gain, packet erasure and random phase each changed 24; phase shuffle changed three. Every difference occurred during movement-locked waiting ticks. No movement-enabled actions, final positions, success outcomes or mean returns changed under any recorded intervention. The communication route was optimized, but these interventions provide no evidence that it affected evaluated task behavior.

The source snapshot fingerprint independently reconstructed from its file manifest matches the recorded run fingerprint. The snapshot is the provenance source for the pilot. Current source differs through rejected-checkpoint-load validation/rollback, its regression tests, and later documentation clarifications/results. The observed numerical initialization, forward and training paths are unchanged. The audit records both source fingerprints and all file diffs.

This audit reads existing artifacts and replays existing conditions. It does not add experiments or alter the raw run directory. Training transport is clean; reference impairment capabilities are not trained robustness evidence. Retention is a longer-delay proxy, and receipts are unsigned change detection rather than authenticity signatures.
